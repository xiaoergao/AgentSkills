# HPM6E AMP 运动固件：可选开发与验收规则

## 适用范围

用于选择采用HPM6E80独立双FreeRTOS AMP、EtherCAT/PDO实时核及网络管理核的目标项目。案例来源为2026-10-12 HPM6E8Y/SDK1.13.0；方法可迁移，但常量须重核。不是所有嵌入式工程的默认规则，也不自动授权下载、运动、擦除或推送。

## 采用时应保留的约束

- 每项跨核RAM区域说明执行地址、访问地址、缓存属性、所有者与DMA可达性；不以SDK函数名称或链接成功代替访问验证。
- 两核ELF、ABI布局描述、Flash资源和加载CRC成套冻结；废弃候选明确标记，不覆盖旧包或混搭镜像。
- 启动阶段分开ready、有效反馈、拓扑核验和运动门控。可重试的幂等初始化列白名单，普通动作不继承自动重放。
- 外设/IRQ/邮箱/DMA单一所有者；共享有界队列不传本地指针。停止与普通处理的通道和排序约束有明确证据。
- RPC认领后超时为未知，未完成槽不可复用。快照冲突保留有效版本并标记年龄，不能把全零响应当作当前设备状态。
- 性能测段不halt调试；同板/同编译/同动作和同负载对照。分别报告板内计算、端到端延迟、交接窗口、吞吐和PDO抖动，不给一个虚假的全局加速倍数。
- 下载预检沿用目标项目要求；未知状态不得凭历史安全授权绕过当前门控。用户当前授权和板卡实况一致时，无需重复索取同一授权。
- Flash配置保留、物理冷启动、真实轴数/接线、空载/带载、电气/长期稳定分别验收。静态资源/host模拟不得冒充现场通过。
