# Windows 桌面内嵌后端 + Web + SQLite：工程组织规则

## 适用范围

仅用于已经决定采用 WPF/WebView2 桌面壳、进程内 ASP.NET Core、Web 前端、本机 SQLite，并以整个 APP 文件夹交付的项目。Windows x64、.NET 10、Vue 3 是可选的具体配置，应以项目约定为准。

本文件不是所有 C# 或 Web 项目的默认规则。独立服务端、多机共享数据库、容器、Electron/Tauri、固件、纯 WPF 原生界面等需要自己的架构约定。目录整理不授权更换技术栈、取消登录或连接生产设备。

## 目录约定

```text
src/                    应用、共享业务、前端、测试、SQL、配置模板、接口和文档
scripts/                构建、验证、运行、发布、备份恢复脚本
temp/                   可再生的所有开发临时文件
  dotnet/               bin、obj、发布暂存
  frontend/             前端开发依赖
  npm-cache/            包管理器缓存
  web/                  网页构建暂存
  tests/                测试数据库、进程状态、测试配置
  package-validation/   复制运行验证的独立 APP
  test-results/         测试报告
artifacts/
  app/                  唯一的活动交付目录
  archive/              如有必要，保留历史证据与恢复快照
```

APP 内部目录依照既有兼容需求确定，可以使用 `resources` / `config` / `data`，也可以沿用内部 `src` / `artifacts` 资源布局；不能要求所有项目改写已存储的附件相对路径。APP 内的资源目录不等于完整源码副本。

- APP 必须包含入口、托管/原生依赖、网页、数据库升级脚本、配置模板和其他实际运行资源。
- 本机配置、SQLite、附件、备份、运行日志和 WebView2 用户缓存必须归入 APP，或明确声明用户选择的外部存储边界。
- 不生成无用途的 Release 副本、重复 ZIP 和多平台依赖。历史版本若承载用户数据或原始证据，先判断保留价值，不能视为缓存删除。
- 开发产生的浏览器截图、测试日志及测试配置进入 `temp`；实际运行日志进入 APP。
- 忽略 `temp`、APP、数据库、凭据及开发依赖；源码与模板可提交。不要提交业务数据和本机秘密。

## 迁移和清理

- 先读路径使用点，再改目录。更新脚本、解决方案、根目录定位、文档与测试，检查从不同工作目录直接启动。
- 关闭相关程序，验证源/目标绝对路径和边界；目标已存在时停止并比对，不直接合并覆盖数据库。
- 配置、数据、备份迁移前后校验文件数和哈希；数据库保持关闭或通过在线一致性备份迁移，避免 WAL 丢失。必要时验证配置文件访问权限。
- `temp` 可再生，但正在执行的构建和测试需要先结束。清理只操作已核实的目标，不跨 Shell 拼接删除路径，不跟随未知符号链接/目录联接。
- `artifacts/app` 不是缓存。升级仅替换程序资源，保留用户状态；历史原始资料按项目证据规则处理。

## 发布与验证

- 构建、相关测试、发布、复制运行验证依次执行。临时数据库不能与开发/生产库共用。
- 固定 APP 更新使用独立暂存并先验证，保留可恢复的上一版程序资源；发布失败不得留下看似成功的半更新目录。
- 明确目标架构、框架依赖或自包含模式、WebView2 前置条件；不要通过删 DLL、盲目裁剪或移除资源来“减少文件数”。
- 校验程序资源清单不包含本机秘密；APP 可携带用户已有状态时，必须明确这与无数据分发包的区别。
- 验证首次初始化、已有状态保留、连续重启与端口/SQLite 锁释放；目录复制验证应清除开发路径环境变量，避免意外依赖原工程。
- 整体复制 APP 前先退出应用，复制后核对目标机器设备地址。未在干净目标机运行时，不能声称无需任何系统组件。

## 与通用规则组合

与通用 .NET 构建发布规则组合时，这里的 `temp` 与 `artifacts/app` 是本产品指定的输出树。通用规则继续约束顺序、锁定依赖、发布验证和失败恢复，不改变此目录边界。

WPF DPI 规则只用于原生壳；Web 前端使用自身 CSS/浏览器布局。ScottPlot 规则仅在实际使用该控件时加载。UTF-8 文本处理、窄范围 Git 暂存和明确中文提交说明可跨架构复用，但不能据此扩大提交或推送范围。
