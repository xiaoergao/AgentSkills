# 验证过的经验及迁移边界

范围：2026-10-31～2026-11-01，在线嘉立创专业版、API Gateway/Bridge、一个核心板底板及其独立测力副本的协作。编辑器/API 版本可能变化；这是历史核对，不代表安装技能时已重新测试当前 EDA。以下不提供完整工程、云端 UUID、私有网表、截图或制造文件。

| 经验 | 现象与处理 | 历史验证 | 未覆盖/迁移要求 |
| --- | --- | --- | --- |
| 多窗口选择 | 原先“恰好一个窗口”的辅助脚本在原工程和副本同时连接时失败；改为逐窗口只读识别工程/文档 | 两个窗口可区分原工程与副本，文档 UUID 相同 | 不依赖历史 windowId；执行中切换图页需要停止并重新识别 |
| 独立复制 | 通过工程文件导入 New Project；副本文档 UUID 沿用原值 | 修改副本后逐对象比较原 PCB、原四路通讯页及核心接口页，与复制前一致 | 不是仅改项目显示名；其他工程/版本要重新证明副本独立 |
| 保存后网表 | 回写源后立即导出曾出现一整页引脚网络暂时为空；保存后重新导出恢复正确 | 排版前后关联板 150 个器件、771 个引脚映射一致 | 观察支持“导出时机/状态未同步”，不宣称已证明内部缓存实现；仍须逐脚比较 |
| 用户样板复制 | 用户把 CH1 的去耦、偏置/终端及保护器件紧凑排列；按角色和原始身份映射复制到另外三路 | CH1 的 407 条相关图元记录保持，771 个引脚网络无变化，导出图人工检查四路一致 | 上述数量只属于该快照；不作为任意工程的断言 |
| 电源符号 | 孤立标签换为 createNetFlag 的 Ground/Power，保持实际网络名 | 30 个标识替换后网表不变，导出图确认旋转和字体 | 专用符号不等于全局网名一定正确；不得合并不同电源域 |
| 同步提示 | 原理图与手工更新后的 PCB 引脚网络已一致，但仍有网表同步提示；正式导入变更刷新关联属性 | 同步后提示清除，器件数量和位置保留；一个连接器实例 ID 被重建 | 同步可能重建实例，必须按位号/Unique ID和焊盘几何复核，不能假设所有 ID 不变 |
| 变体草稿 | 从运动控制底板派生双路 RS485、保留 FPC、四路全桥传感器端子 | 原理图与 PCB 均为 62 个器件，逐脚网络一致 | ADC、激励、模拟滤波、完整布线未完成；不是测量性能或产品验收 |

## 证据如何复用

方法可复用，板型参数不能复制成默认值。新的任务以实时源、已保存网表、当前封装/数据手册和用户样板重新验证。技能中的脚本测试采用虚构数据及模拟服务，只证明目标筛选、拒绝误选和比较逻辑，不代表已在另一台电脑连通 EDA。

原始证据保留在原任务本地的工程源快照、网表对比、源记录对比和 API 导出的 PNG 中；公共仓库只保留这里的结果摘要。需要复审某块实际板时，要求访问该板当前工程，不从这份摘要恢复电气设计。
